# YT_Auto_26

কোড দিয়ে (Remotion) মোশন-গ্রাফিক্স স্টাইলের ভিডিও বানানোর প্রজেক্ট। একাধিক "টেমপ্লেট" রাখা হয়, প্রতিটা একটা রেফারেন্স ভিডিওর স্টাইল থেকে বানানো, আর যেকোনো টপিক/স্ক্রিপ্টের জন্য রিইউজ করা যায়।

## স্ট্রাকচার

```
src/
  templates/
    101/   -> প্রথম টেমপ্লেট (ফজর-টিপস স্টাইল: ওয়ার্ড-বাই-ওয়ার্ড টেক্সট, নাম্বার ট্রানজিশন, আইকন)
    202/   -> পরের টেমপ্লেট (যোগ হলে এখানে থাকবে)
  shared/  -> সব টেমপ্লেটের জন্য কমন কোড (ফন্ট লোডার, হেল্পার ফাংশন)
  Root.tsx -> সব টেমপ্লেট এখানে রেজিস্টার করা থাকে
```

প্রতিটা টেমপ্লেট ফোল্ডারে থাকে:
- `content.ts` — ভিডিওর স্ক্রিপ্ট/টেক্সট (এটাই মূলত এডিট করতে হয়)
- `theme.ts` — কালার, সাইজ, স্পিড
- `brandConfig.ts` — লোগো/সোশ্যাল হ্যান্ডেল/কন্টাক্ট ইনফো
- বাকি ফাইল (`Video.tsx`, `Slide.tsx`, আইকন ইত্যাদি) — অ্যানিমেশনের আসল কোড, সাধারণত ছোঁয়ার দরকার হয় না

## রান করা

```bash
npm install
npm start               # প্রিভিউ এডিটর (Remotion Studio)
npm run render:101      # Template101 রেন্ডার করে out/template-101.mp4 বানাবে
```
